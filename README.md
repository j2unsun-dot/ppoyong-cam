# 뽀용캠

아이폰 홈 화면에 추가해서 쓰는 필터 카메라 웹앱.

- 실시간 필터 촬영 / 앨범 사진 불러와서 필터 적용
- 뽀용(버터·햇살·웨딩·피치·우유), 리코(포지티브·네거티브·하이콘 흑백·블리치·진득), 필름(시네마·후지 무비·코닥 무비·초록 필름·밤 영화)
- 세부 조정: 강도·밝기·대비·채도·색온도 (필터 위에 덧입힘)
- 자동밝기: 실내·조명 아래에서도 필터 색감이 비슷하게 유지되도록 밝기와 조명 색을 먼저 보정

무음 촬영(셔터 소리 없음).

설치: Safari에서 열기 → 공유 → 홈 화면에 추가

## 수정하는 법
`src/` 안의 파일을 고친 뒤 `python3 build.py`로 `index.html`을 다시 만들어 올리면 됩니다.
