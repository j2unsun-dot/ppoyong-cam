# 필름캠

아이폰 홈 화면에 추가해서 쓰는 필름 색감 카메라 웹앱. 과한 효과 없이 색만 자연스럽게.

**👉 앱 열기: https://j2unsun-dot.github.io/ppoyong-cam/**

<img src="icons/share-qr.png" width="260" alt="필름캠 QR 코드">

- 필름: 내추럴 · 아그파 100 · 아그파 200 · 코니카 · 포트라 · 골드 · 후지 C200 · 흑백
- 조정: 필름 강도 · 노이즈 · 블러 · 밝기 · 대비 · 채도 · 색온도 (화면으로 보면서 조절)
- 고화질: 아이폰 기본 카메라로 찍고(원본 화소·초점) 바로 필름 색 입히기
- 앨범 사진 불러와서 보정, 무음 촬영, 자동밝기(어두운 실내·강한 조명색만 살짝 보정)

설치: Safari에서 열기 → 공유 → 홈 화면에 추가

## 수정하는 법
`src/` 안의 파일을 고친 뒤 `python3 build.py`로 `index.html`을 다시 만들어 올리면 됩니다.
